# Getting started with agent-voice-chat

AI voice chat with two agents (Bob & Alice) - speak to them and they speak back

## Install

```bash
npm install
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/agent-voice-chat.git
cd agent-voice-chat
```

Available commands:

| Command | Runs |
|---|---|
| `npm run start` | `node server.js` |
| `npm run dev` | `node --watch server.js` |
| `npm run build` | `tsc` |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run test` | `vitest run` |
